# booking — service đặt lịch (Laravel)

Service Laravel đặt lịch của BranchBook: chuỗi, chi nhánh, phòng, slot, gói hội viên, đặt/huỷ chống trùng.

Lệnh chạy và test nằm ở `README.md` + `Makefile` thư mục gốc repo (chạy từ gốc): `make setup` (lần đầu sau khi clone), `make up`, `make test`.

Truy cập qua gateway `http://localhost:8100/booking` hoặc trực tiếp `http://localhost:8180`.
